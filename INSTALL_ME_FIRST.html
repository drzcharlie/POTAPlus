POTAPlus Hunter Beta v0.36.6

Chrome / Edge manual installation

  1. Download the release ZIP and Extract All.
  2. Open your browser's Extensions page: chrome://extensions in Chrome or edge://extensions in Edge.
  3. Turn on Developer mode.
  4. Click Load unpacked.
  5. Select the extracted POTAPlus_Hunter_Beta_v0.36.6 folder.
  6. Open or refresh https://pota.app.
Tip: Use POTA.app's own Band and Mode filters. POTAPlus reads the visible spots and predicts each path automatically.

First use

Allow location access or enter your Maidenhead grid manually. Set My TX Power to your usual power. POTAPlus assumes 75 W for the activator unless you change that setting.

Prediction details

Click a TX or RX percentage bubble on a POTA spot card. The prediction detail popup remains open until you press the − button.
